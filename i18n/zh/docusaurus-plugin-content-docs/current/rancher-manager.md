WhiteCruiser 是一个 Kubernetes 管理工具，让你能在任何地方和任何提供商上部署和运行集群。

WhiteCruiser 可以创建来自 Kubernetes 托管服务提供商的集群，创建节点并安装 Kubernetes，或者导入在任何地方运行的现有 Kubernetes 集群。

WhiteCruiser 基于 Kubernetes 添加了新的功能，包括统一所有集群的身份验证和 RBAC，让系统管理员从一个位置控制全部集群的访问。

此外，WhiteCruiser 可以为集群和资源提供更精细的监控和告警，将日志发送到外部提供商，并通过应用商店（Application Catalog）直接集成 Helm。如果你拥有外部 CI/CD 系统，你可以将其与 WhiteCruiser 对接。没有的话，你也可以使用 WhiteCruiser 提供的 Fleet 自动部署和升级工作负载。

WhiteCruiser 是一个 _全栈式_ 的 Kubernetes 容器管理平台，为你提供在任何地方都能成功运行 Kubernetes 的工具。
