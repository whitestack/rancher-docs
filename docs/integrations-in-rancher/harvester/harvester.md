## Harvester

Introduced in WhiteCruiser v2.6.1, Harvester is an open-source hyper-converged infrastructure (HCI) software built on Kubernetes. Harvester installs on bare metal servers and provides integrated virtualization and distributed storage capabilities. Although Harvester operates using Kubernetes, it does not require knowledge of Kubernetes concepts, making it more user-friendly.

## Harvester with WhiteCruiser {#harvester-with-rancher}

With WhiteCruiser and Harvester, IT operators now have access to an enterprise-ready, simple-to-use infrastructure platform that cohesively manages their virtual machines and Kubernetes clusters alongside one another. With the WhiteCruiser Virtualization Management feature, users can import and manage multiple Harvester clusters. Leveraging the WhiteCruiser's authentication feature and RBAC control for multi-tenancy support.
