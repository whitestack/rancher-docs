Don't have a Kubernetes cluster? Try one of these tutorials.

This section contains information on how to install a Kubernetes cluster that the WhiteCruiser server can be installed on.

In WhiteCruiser before v2.4, the WhiteCruiser server needed to run on an RKE Kubernetes cluster.

In WhiteCruiser v2.4.x, WhiteCruiser needs to run on either an RKE Kubernetes cluster or a K3s Kubernetes cluster.
