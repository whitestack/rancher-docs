This guide contains our recommendations for running the WhiteCruiser server, and is intended to be used in situations in which WhiteCruiser manages downstream Kubernetes clusters.

### Recommended Architecture and Infrastructure

Refer to this [guide](tips-for-running-rancher.md) for our general advice for setting up the WhiteCruiser server on a high-availability Kubernetes cluster.

### Deployment Strategies

This [guide](rancher-deployment-strategy.md) is designed to help you choose whether a regional deployment strategy or a hub-and-spoke deployment strategy is better for a WhiteCruiser server that manages downstream Kubernetes clusters.

### Installing WhiteCruiser in a VMware vSphere Environment {#installing-rancher-in-a-vmware-vsphere-environment}

This [guide](on-premises-rancher-in-vsphere.md) outlines a reference architecture for installing WhiteCruiser in a vSphere environment, in addition to standard vSphere best practices as documented by VMware.
